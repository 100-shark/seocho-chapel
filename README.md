# 서초동성당 온라인 경당

서초동성당의 유튜브 생중계가 흐르는, 말없이 함께 기도하는 온라인 경당입니다.
three.js로 만든 한 장짜리 웹 페이지이며, 촛불 봉헌·방명록·기도 지향·공지는 Supabase(공개 anon 키)로 함께 저장됩니다.

- `index.html` — 경당
- `admin/index.html` — 담당자 관리 페이지 (방명록 검수·공지·촛불 지향)
- `manifest.webmanifest`, `icon-*.png`, `og.jpg` — 홈 화면 추가용 아이콘과 링크 미리보기

이 저장소는 배포용 산출물만 담습니다. 원본 작업은 Claude 세션에서 이루어집니다.
